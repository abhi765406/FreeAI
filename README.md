# Claude AI (Android) – white-screen fix

Drop these 2 files into your repo, overwriting the existing ones (same paths):

    app/src/main/java/com/claudeai/app/MainActivity.java
    app/src/main/assets/claude.html

Nothing else changes. AndroidBridge.java, AndroidManifest.xml, build.gradle, resources: untouched.

## IMPORTANT – check your build for patch.py
The old APK contained assets/README_PLACEHOLDER.txt saying claude.html is generated by
`patch.py` from the original claude/Claude.html. If your build (Gradle task or GitHub Action)
runs patch.py, it will OVERWRITE this fixed claude.html. Remove/disable that step
(or copy the fixed file over the generated one after it runs).

## Recommended (optional) in app/build.gradle
targetSdk / targetSdkVersion 28 -> 34   (removes the "built for an older Android version" warning on new phones)
